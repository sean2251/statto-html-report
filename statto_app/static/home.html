Your seasons

Welcome! A season is one team’s Statto export plus everything you add to it — tournaments, video links, lines and video tags. It all saves to a folder on this computer.

  1. In Statto, export your team (you’ll get a .statto file).
  2. Create a season from it below, then open its editor.
  3. Whenever you’ve stat’d more games, export again and use Add newer Statto export on the season.

Settings
Seasons folder

Where your seasons are saved. Each season is a normal folder you can back up or copy.

Shared tagging site

The address you send helpers along with a game file. Leave as is unless you host your own copy of the tagging site (download it · preview).

My own tagging site folder (optional)

If you host tagging pages yourself — e.g. a GitHub repo that Cloudflare Pages deploys — choose your local copy of it. “Publish to my site” then saves the page there and, if it’s a git repository, commits and pushes it for you.
