Set up this site

This is a new site: choose the admin password. To prove it’s you, the site puts a one-time setup code in its logs, which only your Cloudflare account can see.

  2. In Cloudflare, open Workers & Pages → this site → Observability (or Logs), and find the line “Statto team site setup code”. It can take a minute to appear; refresh the logs if it isn’t there yet.
  3. Enter the code and choose the admin password (at least 10 characters).

Reset the admin password

Choose a new admin password. To prove it’s you, the site puts a one-time reset code in its logs, which only your Cloudflare account can see. Everyone signed in with the old password is signed out.

  2. In Cloudflare, open Workers & Pages → this site → Observability (or Logs), and find the line “Statto team site password reset code”. It can take a minute to appear; refresh the logs if it isn’t there yet.
  3. Enter the code and choose the new password (at least 10 characters).
